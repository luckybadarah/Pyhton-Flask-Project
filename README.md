# Emotion Detector

Final Project for the IBM Developing AI Applications with Python and Flask course.

## Project Overview

This project is an AI-based Emotion Detector web application that uses the IBM Watson NLP Emotion Prediction service to analyze text and identify the dominant emotion.

## Features

- Detects emotions from user input
- Returns anger, disgust, fear, joy, and sadness scores
- Displays the dominant emotion
- Flask web interface
- Unit tests
- Error handling
- Static code analysis using pylint

## Technologies Used

- Python
- Flask
- IBM Watson NLP
- Requests
- Pylint
